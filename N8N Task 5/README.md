# N8N Task 5: Slack AI Assistant

## Project Overview

This project demonstrates an AI-powered Slack assistant built using n8n. It connects Slack with an AI Agent to process messages and provide automated responses.

## Workflow Features

- Receive incoming Slack messages through Slack Trigger.
- Handle direct messages and channel mentions.
- Process incoming messages using an AI Agent.
- Generate AI-powered responses.
- Send responses back to Slack.
- Avoid duplicate replies through appropriate trigger configuration.

## Technologies Used

- n8n
- Slack
- AI Agent
- OpenAI Chat Model

## Files Included

- Slack workflow JSON export.

## Setup Instructions

1. Import the workflow JSON file into n8n.
2. Configure your own Slack credentials.
3. Configure the required AI model credentials.
4. Review the Slack Trigger settings.
5. Test direct messages and channel mentions.
6. Activate the workflow.

**Note:** Credentials must be configured before running the workflow.
